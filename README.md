# monotrat

**Куди ж поділись гроші?** Розширена аналітика витрат monobank у стилі [дашборду mono](https://monobank.ua/dashboard).

👉 **https://saintsereda.github.io/monotrat/** · [демо з вигаданими даними](https://saintsereda.github.io/monotrat/?demo)

Вставляєте персональний токен з [api.monobank.ua](https://api.monobank.ua/) — і отримуєте:

- 🛒 витрати за категоріями (за MCC) і які категорії зросли чи впали;
- 🏆 топ-10 мерчантів, топ у кожній категорії, нові місця, куди ходите найчастіше;
- 📈 прогноз витрат і доходів на кінець місяця, порівняння з минулим місяцем, середнім за 3 місяці й торішнім;
- 📅 теплову карту днів, найвитратніші дні, «день тижня × година», дні без витрат;
- 🔁 підписки й регулярні платежі (і коли вони подорожчали);
- ⚠️ незвичні покупки, дорогі дні, сплески категорій;
- 💸 доходи й витрати за 13 місяців і цікаві факти про ваші звички.

## Приватність

- Немає сервера: браузер звертається напряму до `api.monobank.ua` (CORS дозволений), токен нікуди більше не йде.
- Токен лише читає виписку. За замовчуванням живе тільки у вкладці (`sessionStorage`), з галочкою «Запам'ятати» — у `localStorage`.
- Транзакції кешуються в IndexedDB вашого браузера. «Вийти і стерти дані» видаляє все.
- Жодної аналітики, трекерів чи сторонніх скриптів; шрифти self-hosted; суворий CSP.

## Як це працює

monobank віддає виписку не частіше ніж раз на 60 секунд і максимум за 31 добу за запит. Тому monotrat вантажить історію помісячно у фоні: спершу поточний місяць по картках (дашборд оживає за ~хвилину), далі ФОП і банки, далі попередні місяці — до 13. Повторні візити дозавантажують лише нове.

## Розробка

```bash
npm install
npm run dev      # http://localhost:5173 (демо: /?demo)
npm test         # Vitest
npm run build    # статичні файли в dist/
```

Стек: Vite, React 19, TypeScript, Tailwind CSS 4, Vitest, `idb`, `d3-shape`. Деплой — GitHub Pages через Actions на кожен пуш у `main`.

Структура: `src/api` (клієнт mono) · `src/sync` (черга з лімітом запитів) · `src/store` (IndexedDB) · `src/analytics` (чисті функції метрик) · `src/ui` (екрани й графіки) · `src/demo` (генератор демо-даних).
